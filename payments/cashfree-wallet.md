# Cashfree Wallet

Cashfree Wallet is a wallet in India that an [MCP](../glossary.md#mcp) server can pay from. The user tops it up and sets the rules; the agent pays bills through India's [Bharat Bill Payment System (BBPS)](../glossary.md#bbps) and never sees the user's card, UPI or bank details.[^cf-01][^cf-02]

## How an agent connects

- Cashfree's AgentPay MCP server is at `https://mcp.cashfree.com/agentpay/mcp` in production, with a sandbox at `https://sandbox.cashfree.com/agentpay/mcp`. Agent builders need AgentPay access and a client API key, which Cashfree's sales team sets up. A Cashfree merchant account is not required.[^cf-03]
- The consumer wallet is in invite-only beta. The user links it to an agent with a mobile OTP.[^cf-01]

## What the agent can pay

- **Bills, today.** The docs say an agent can pay everyday bills such as electricity, water, mobile and broadband through BBPS. Cashfree's consumer page describes live bills as electricity, Wi-Fi and mobile.[^cf-01][^cf-02]
- **Coming soon.** Travel, food, groceries and shopping are listed as coming soon on the consumer page. They are not live.[^cf-01]

## Who approves what

- On the consumer page, the user approves each task up front with a budget: how much, how many payments, and how long consent lasts. The user can revoke the agent's access at any time and gets an alert for every payment.[^cf-01]
- The AgentPay docs describe a first-time consent: the customer opens a link, logs in with an OTP, and approves a mandate, a standing permission to pay bills from the wallet up to a monthly limit.[^cf-02]
- The agent never sees card, UPI or bank details.[^cf-01]
- Cashfree says the MCP server stores nothing, and never keeps keys, tokens or bill data.[^cf-02]

Cashfree says 100+ agents are already integrated. That figure is Cashfree's own claim on its consumer page.[^cf-01]

## Unknown
