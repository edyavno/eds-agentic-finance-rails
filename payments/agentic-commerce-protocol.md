# Agentic Commerce Protocol (ACP)

ACP is an open standard for connecting buyers, their AI agents and businesses so they can complete purchases. OpenAI and Stripe maintain the specification, and it is in beta.[^pm-07]

## What is in the spec

- A checkout API for businesses, and a separate delegated-payment spec. Both are published as [OpenAPI](../glossary.md#openapi) files.[^pm-07]
- For AI apps, the repo says an app can let users buy directly from businesses without the app being the seller.[^pm-07]
- OpenAI and Stripe were the first to implement it.[^pm-07] Stripe's side is on the [Stripe](stripe.md) page.

ACP is a spec, not a hosted service, so there is no endpoint.
