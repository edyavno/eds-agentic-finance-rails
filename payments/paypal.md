# PayPal

PayPal's agent tools are for businesses that use PayPal. They let an AI agent work with PayPal's APIs.[^pm-11]

## MCP server

- You can run the [MCP](../glossary.md#mcp) server yourself or use PayPal's hosted one.[^pm-10]
- The local server needs Node.js 18 or later and a PayPal access token, set for the [sandbox](../glossary.md#sandbox) or for production.[^pm-10]
- Hosted addresses: `https://mcp.paypal.com` for production and `https://mcp.sandbox.paypal.com` for the sandbox. The hosted server can use your PayPal client ID and secret.[^pm-10]

## Agent toolkit

- Pre-built functions for orders, invoices, subscriptions, shipment tracking, transaction details and disputes.[^pm-11]
- Works with Amazon Bedrock, CrewAI, LangChain, MCP, OpenAI's Agents SDK and Vercel's AI SDK, in TypeScript and Python.[^pm-11]
