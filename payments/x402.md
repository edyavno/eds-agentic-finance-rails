# x402

[x402](../glossary.md#x402) is an open payment standard built on HTTP. It lets a client, such as an agent, pay for something it asks a website for.[^pm-14][^pm-15]

## How it works

1. The client asks for a resource.
2. If no valid payment is attached, the server replies with a "payment required" signal and its payment terms.[^pm-15]
3. The client sends the request again with a payment.
4. A facilitator, a service that checks and settles payments, can handle verification and settlement on a blockchain.[^pm-15]

The spec names several payment schemes, including `exact`, `upto` and `batch-settlement`.[^pm-15] The project says it aims to support both crypto and traditional payment networks, and forms of value including [stablecoins](../glossary.md#stablecoin).[^pm-14]

x402 is a standard, not a hosted service, so there is no single endpoint.

## x402 request flow

The same four steps as a sequence. What a person approves before an x402 payment depends on the agent or wallet and is unknown.

## Where it shows up

- Coinbase for Agents lets an agent pay for data and research with x402 from a USDC balance.[^cb-01] See [Coinbase](../providers/coinbase.md).
- Mastercard says its Agent Pay for Machines builds on x402 and connects it with the Mastercard network. It is in Early Access for developers.[^pm-23] See [Mastercard Agent Pay](mastercard-agent-pay.md#what-is-agent-pay-for-machines).
- AWS Marketplace now supports agentic payments over x402 through Amazon Bedrock AgentCore payments. Agents pay per request in US dollars on the customer's AWS bill, with no crypto wallet, and customers can set spending limits and approved sellers first.[^aw-01] See [Amazon Bedrock AgentCore payments](agentcore-payments.md).
- AWS's AgentCore payments guide lists the Machine Payments Protocol ([MPP](../glossary.md#mpp)) alongside x402. It says both use the HTTP 402 Payment Required status code.[^aw-03]
- [pay.sh](https://pay.sh/) is a client and gateway for paying HTTP 402 challenges over x402 and MPP in stablecoins on Solana. The pay.sh site says it is built on those protocols, with settlement paths for calls as little as $0.001. A 2026-05-05 Solana Foundation announcement said it launched Pay.sh with Google Cloud, including Gemini and BigQuery among the first APIs, with no account, API key or subscription required.[^pm-33][^so-01]
- [Visa CLI](visa-cli.md) agents can pay per-request APIs that answer with HTTP 402, in [OUSD](../glossary.md#ousd) on [Tempo](../glossary.md#tempo), within owner-set limits. Whether that live path uses the x402 protocol is unknown; Visa CLI's status docs tell merchants to test payment handling with an MPP server.[^pm-27][^pm-28]

## Unknown

What a person approves before an x402 payment depends on the agent or wallet. The spec sources do not say. No cited source confirms it, so the wiki says unknown.
