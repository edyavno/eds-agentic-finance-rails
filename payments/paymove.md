# paymove

paymove is a payments company in Poland. Its AI Payments docs describe agents that can browse a merchant catalog and pay with [BLIK](../glossary.md#blik) on the user's behalf.[^pv-01]

## How an agent connects

- Text agents connect as large language models through an [MCP](../glossary.md#mcp) server, with tools to browse the catalog, make a BLIK payment and see transaction history. The docs also describe a voice-agent path.[^pv-01]
- The address of the MCP server is not in the pages cited here, so it is unknown.

## Who approves what

- Each payment is a fresh BLIK transaction, confirmed with a code from the customer's banking app. The docs say the agent never pays automatically, without a person taking part in that transaction.[^pv-01]
- Amount limits (guardrails) configured in the Agent Panel are not enforced on BLIK payments today. The docs say no integration checks those limits before starting a payment, and that safety currently comes only from the person confirming each BLIK payment in the banking app.[^pv-01]

## The x402 mode, which is off

A separate wallet-balance mechanism can make automatic [x402](../glossary.md#x402) payments without BLIK confirmation. The docs say that mechanism is switched off for now.[^pv-01] See [x402](x402.md).

## Who can use it

BLIK is a Polish payment method, so this is for payments in Poland. A paymove marketing page lists ChatGPT, Claude and Grok under a heading that they are available from November 2026. That is paymove's own marketing claim; whether each of those apps is actually live is unknown.[^pv-02]

Fees are not in the pages cited here, so they are unknown.
