# Amazon Bedrock AgentCore payments: Enable secure microtransaction payments for AI agents

**Official source** · Amazon Web Services (AgentCore Developer Guide) · official-doc · retrieved 2026-11-20 · [open the original](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments.html)

## Summary

Developer guide page for Amazon Bedrock AgentCore payments, a fully managed AWS service for microtransaction payments by AI agents to paid APIs, MCP servers and content. It supports the x402 protocol and the Machine Payments Protocol (MPP), both built on HTTP 402. Each payment session has a budget limit and an expiry time. Wallet integration is with two providers, CoinbaseCDP and Stripe(Privy), and an AWS Billing connector lets agents pay AWS Marketplace sellers without a crypto wallet.

## Short quotes

> With AgentCore payments, you can orchestrate payments using open HTTP-native standards, including the x402 protocol and the Machine Payments Protocol (MPP). Both protocols use the HTTP 402 Payment Required status code for programmatic payments.

> Each PaymentSession has a configurable budget limit (maxSpendAmount, currency) and an expiry time. When the session expires or the budget is reached, further payment requests are denied.

> The service offers secure wallet integration with two providers: CoinbaseCDP and Stripe(Privy) for embedded stablecoin wallet operations.

> With an AWS Billing connector, agents can pay AWS Marketplace sellers that accept x402 payments, and they don’t need a crypto wallet.
