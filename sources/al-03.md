# GitHub - alpacahq/agentic: Multi-platform plugin marketplace for Alpaca APIs · GitHub

**Official source** · Alpaca (GitHub) · repo · retrieved 2026-11-19 · [open the original](https://github.com/alpacahq/agentic)

## Summary

alpacahq/agentic: hosted plugins, remote OAuth MCP servers, local Trading MCP, CLI. Plugins are the easiest way to connect Cursor, Claude Code or Codex to Alpaca's hosted OAuth-protected MCP endpoints; hosted MCP access currently supports those three clients through plugins, with manual remote JSON configurations also given. Plugin install: Cursor via marketplace import from https://github.com/alpacahq/agentic; Claude Code via `claude plugin marketplace add alpacahq/agentic` then /plugin, /reload-plugins and /mcp; Codex via `codex plugin marketplace add alpacahq/agentic` then `codex mcp login <mcp-name>`. Each installed MCP server completes a browser-based OAuth flow.
