# Solana Foundation Launches Pay.sh in Collaboration with Google Cloud

**Official source** · Solana Foundation · announcement · retrieved 2026-11-23 · [open the original](https://solana.com/news/solana-foundation-launches-pay-sh-in-collaboration-with-google-cloud)

## Summary

Solana Foundation announcement dated 5 May 2026. In collaboration with Google Cloud, it launched Pay.sh, a gateway so agents can discover, access, and pay per request for APIs using stablecoins on Solana, without accounts, API keys, or subscriptions. Launch APIs included Google Cloud services such as Gemini, BigQuery, and the Gemini Enterprise Agent Platform. The announcement says Pay.sh is built on x402 and MPP.
