# How are orders approved and protected when using Scalable MCP? | Scalable Capital Help Center

**Official source** · Scalable Capital Help Center · support · retrieved 2026-11-19 · [open the original](https://help.scalable.capital/en/agentic-investing-aac939f8/how-are-orders-approved-and-protected-when-using-scalabl-d16595b5)

## Summary

Order approval: buy and sell orders only at the "Full access" level; the agent prepares the order, you review details, costs, disclosures and warnings and explicitly confirm in a separate step; an order preview does not place an order; Scalable's standard checks continue to apply; the CLI's access setting is managed separately.

## Short quotes

> Buy and sell orders via Scalable MCP are only possible with the "Full access" level.

> In Read-only mode and under "Limited changes", no buy or sell orders can be submitted.

> An order preview does not place an order. An AI agent cannot place a buy or sell order without your renewed, explicit confirmation.

> The access setting for the Scalable CLI is managed separately and is not affected by the selected MCP access level.
