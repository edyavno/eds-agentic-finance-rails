# Webull Cloud MCP Server | Webull API

**Official source** · Webull Developer · official-doc · retrieved 2026-11-19 · [open the original](https://developer.webull.com/apis/docs/AI-friendly-Resources/mcp/)

## Summary

Cloud MCP https://api.webull.com/mcp; OAuth authorization code flow; per-account capabilities: Non-Trading or Trading (generate trade instructions). Users may authorize one or more accounts, and only selected accounts are accessible through MCP. Market data permissions match the Webull App account; OpenAPI market data subscriptions cannot be used with Cloud MCP. Order instructions require confirmation in the Webull app or desktop; revoke_instruction revokes a previously created order instruction, with get_pending_instruction and get_processed_instruction alongside, and get_account_authorization shows the MCP authorization. Non-Trading tools include community posting: create_community_post and create_community_comment publish under your account. Connection examples cover ChatGPT, Claude and Grok (video guides), Codex, Cursor, Kiro, Zed and Cherry Studio.

## Short quotes

> Webull Cloud MCP uses OAuth Authorization Code Flow.

> Create a stock order instruction (requires confirmation in Webull APP / Desktop).

> Create a plain-text community post, optionally tagged with a symbol (publishes under your account).

> Revoke a previously created order instruction.
