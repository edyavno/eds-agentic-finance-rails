# Enable AI agents to pay for AWS Marketplace x402 products with Amazon Bedrock AgentCore payments

**Official source** · Amazon Web Services (AWS Machine Learning Blog) · announcement · retrieved 2026-11-20 · [open the original](https://aws.amazon.com/blogs/machine-learning/enable-ai-agents-to-pay-for-aws-marketplace-x402-products-with-amazon-bedrock-agentcore-payments/)

## Summary

AWS Machine Learning Blog post of 2026-11-19. It says AgentCore payments became generally available in August 2026 and that AWS Billing is now a payment option, so an agent can pay x402-enabled AWS Marketplace sellers per request in US dollars on the AWS bill. It walks through the flow: the seller answers HTTP 402 with a signed quote, AgentCore payments checks the session budget and returns a payment token, and the agent retries with the token. It also describes a sample setup with a spending limit per payment session.

## Short quotes

> When Amazon Bedrock AgentCore payments became generally available in August 2026, agents could autonomously pay for paid APIs, MCP servers, and web content over open protocols like x402 and MPP with payment limits and full observability.

> If budget remains in the session, AgentCore payments issues a payment token. If not, the call fails and the developer is not charged.

> The session role can set budgets but can’t pay. Meanwhile the agent role can pay but can’t create sessions, so the agent has no way to raise its own budget.

> Payment tokens are valid for about five minutes, so the agent completes steps 2 through 4 in a single pass.
