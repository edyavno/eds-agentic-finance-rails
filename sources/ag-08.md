# Configure thresholds - AgentBank docs

**Official source** · AgentBank · official-doc · retrieved 2026-11-19 · [open the original](https://docs.useagentbank.com/autonomy/configure-thresholds)

## Summary

AgentBank's guide to the payment-approval threshold: it is viewed and changed at app.useagentbank.com, and it helps determine which payments can proceed without an additional World ID action; AgentBank may still require approval based on the current payment and account policy. Local MCP connections can also ask the agent to read or change the threshold, with the proposed change shown before it is applied; these policy tools are specific to local MCP connections. Changing the threshold does not replace payment review, verification or a separate wallet-funding confirmation. The docs do not state the threshold amounts.
