# X Money plugin README (cursor/plugins, third_party/x-money)

**Official source** · cursor/plugins (GitHub) · repo · retrieved 2026-11-18 · [open the original](https://raw.githubusercontent.com/cursor/plugins/main/third_party/x-money/README.md)

## Summary

README for the Grok Bot plugin that connects agents to X Money through X Money's hosted MCP server at https://mcp.money.x.com/mcp. It says the plugin can use the X Money card, send money to users on X, show the balance and browse transactions. Sign-in is OAuth with a connection code or QR code approved with a passkey in the X Money app; the code lasts about 5 minutes and the connection can be revoked at X > Money > Settings > Connections. Every action that moves money gets its own Approve or Cancel prompt, X Money refuses calls that were not approved, agents have separate limits, higher-risk transfers stay in the X app, and X Money decides which actions each account gets.

## Short quotes

> Every action that moves money is confirmed with you first.

> X Money also enforces this on its side and refuses any such call that was not approved.

> Higher-risk transfers stay in the X app and are not available to agents.

> The agent never sees your X Money password, passkey, or bank credentials.
