# Claude & Claude Code Connector for Stock & Options Trading on Public MCP

**Official source** · Public.com API docs · official-doc · retrieved 2026-11-19 · [open the original](https://public.com/api/docs/templates/claude)

## Summary

Claude & Claude Code connector setup for Public MCP.

## Short quotes

> The Public connector in the official Claude connector directory cannot place trades.

> The directory connector can't place trades, including from Claude Code.

> Adding connectors on mobile is in beta. If you already added Public as a custom connector on web or desktop, it's available in the iOS app the next time you sign in, and you can skip these steps.

> Claude uses the accounts and trading permissions you authorize when you connect. Options strategies require the appropriate approval level.
