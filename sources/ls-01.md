# Lightspark Launches Agent Accounts for AI Agents to Make and Receive Payments

**Official source** · Lightspark (via GlobeNewswire) · announcement · retrieved 2026-11-20 · [open the original](https://www.globenewswire.com/news-release/2026/11/17/3405071/0/en/lightspark-launches-agent-accounts-for-ai-agents-to-make-and-receive-payments.html)

## Summary

Lightspark press release of 2026-11-17 launching Agent Accounts, which let AI agents hold, spend, send and receive money for a person or business. Account holders set spending limits and decide which payments need their approval. At merchants that accept Visa the agent pays with a card valid for that purchase alone, or with a saved card it sees only as a card ID. Businesses can pay suppliers over ACH and contractors through Pix. The release says Agent Accounts is available today to companies building agents.

## Short quotes

> Account holders set spending limits and decide which payments need their approval.

> When a consumer pays from their account balance, the agent uses a Visa card valid for that purchase alone. Consumers can also pay with a saved card, in which case the card number stays in a secure vault and the agent sees only a card ID.

> Lightspark connects the account to banks and local payment networks in 65 countries, while Spark handles settlement between Agent Accounts.

> Agent Accounts is available today to companies building agents for consumers, small businesses and merchants.
