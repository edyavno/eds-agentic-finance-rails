# Visa CLI docs: What's live today

**Official source** · Visa CLI docs (Visa Crypto Labs) · official-doc · retrieved 2026-11-23 · [open the original](https://app.visacli.sh/docs/status)

## Summary

Visa CLI status documentation, updated 21 November 2026. Visa CLI is built by Visa Crypto Labs and is a Visa product. Since 18 November 2026, a newly connected agent's key is registered in the Visa Agent Directory at https://agenticdirectory.visa.com. Agents connected before then remain in the Visa Agent Directory sandbox. Visa CLI's registry at https://auth.visacli.sh lists agents and names whether each key is in the production directory or the sandbox; that host is also the API and the hosted MCP server. The card step, wallet money in OUSD on Tempo mainnet, task payouts, signatures, and new agents' TAP listings are described as real today. The current rule is one card, one person, and up to 25 agents, with many agents on the same wallet. Accounts are approved by invitation. The card step runs through VGS with a real US Visa card. The docs say they are private for now and that an agent reads them with a docs key; this page was retrieved from the public docs URL. The exact MCP path is not given.
