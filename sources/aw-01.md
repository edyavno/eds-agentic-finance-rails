# AWS Marketplace now supports agentic payments with AgentCore

**Official source** · Amazon Web Services · announcement · retrieved 2026-11-20 · [open the original](https://aws.amazon.com/about-aws/whats-new/2026/11/marketplace-agentic-payments-agentcore/)

## Summary

AWS What's New post of 2026-11-19. AWS Marketplace now supports agentic payments over the x402 protocol, so AI agents can discover and buy select products and pay per request in US dollars through AgentCore payments. Charges settle on the customer's existing AWS bill with no crypto wallet required. Customers can set spending limits, approved sellers and guardrails before agents transact. Sellers integrate the AWS Marketplace x402 SDK.

## Short quotes

> AWS Marketplace now supports agentic payments over the x402 protocol, so AI agents can discover and buy select products and pay per request in US dollars through AgentCore payments, part of Amazon Bedrock AgentCore.

> charges settle on their existing AWS bill with no crypto wallet required.

> Customers can set spending limits, approved sellers, and guardrails before agents transact, Private Marketplace policies still apply, and transactions appear in AWS CloudTrail and AWS Cost Explorer.

> The capability is available in all AWS Regions where AgentCore payments is available.
