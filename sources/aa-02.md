# Get Started with Aave MCP

**Official source** · Aave · official-doc · retrieved 2026-11-23 · [open the original](https://aave.com/docs/mcp/getting-started)

## Summary

Aave getting-started documentation for Aave MCP. The server is remote: there is nothing to install and no key to manage. Clients point at `https://mcp.aave.com` over Streamable HTTP, with no authentication. The docs say the endpoint needs no key today, that it is a shared service, and that clients should handle 401 and 429 responses. Numeric limits are not given. The server also carries five ready-made prompts: `check_health`, `best_stablecoin_yield`, `prepare_supply`, `gho_savings`, and `review_position`. The page has no publication date.

## Short quotes

> Aave MCP is a remote server, so there is nothing to install and no key to manage. Point a client at `https://mcp.aave.com` and the tools appear in the next session.

> Choose Streamable HTTP wherever a client offers a transport dropdown.

> The endpoint needs no key today.

> Reads answer with live protocol data. Actions come back as an unsigned transaction for the user to sign in their own wallet.
