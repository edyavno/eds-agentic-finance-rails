# AI Payments

**Official source** · paymove · official-doc · retrieved 2026-11-27 · [open the original](https://docs.paymove.io/products/ai-payments)

## Summary

paymove's AI Payments documentation (in Polish). AI agents, including large language models connected through MCP and a voice agent, can browse a merchant catalog and pay with BLIK on the user's behalf. Each payment is a fresh BLIK transaction confirmed with a code from the banking app; the docs say the agent never pays automatically, without a person taking part in that transaction. A separate wallet-balance mechanism for automatic x402 payments without BLIK confirmation exists but is switched off. Amount limits (guardrails) configured in the Agent Panel are not enforced on BLIK payments today; the docs say safety currently comes only from the person confirming each BLIK payment in the banking app. The MCP address, fees, and a launch date are not stated on this page.

## Short quotes

> Każda płatność to osobna, świeża transakcja BLIK, potwierdzana kodem z aplikacji bankowej - obecnie agent nigdy nie płaci automatycznie, bez udziału człowieka w danej transakcji.

> Saldo portfela dotyczy innego mechanizmu (automatyczne płatności x402 bez potwierdzenia BLIK), który na ten moment jest wyłączony

> Guardrails (limity kwotowe) skonfigurowane dla agenta w Agent Panel nie są dziś egzekwowane przy płatności BLIK - żadna z integracji nie sprawdza ich przed zainicjowaniem płatności.
