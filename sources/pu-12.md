# ChatGPT & Codex Connector for Stock & Options Trading on Public MCP

**Official source** · Public.com API docs · official-doc · retrieved 2026-11-19 · [open the original](https://public.com/api/docs/templates/chatgpt)

## Summary

ChatGPT and Codex setup for the Public hosted MCP: ChatGPT plugin via Plugins > Browse Directory > Add custom MCP server (OAuth, risk box); Codex via codex mcp add / codex mcp login. ChatGPT can require extra approval for write actions such as placing orders by default.

## Short quotes

> By default, ChatGPT can require additional approval before write actions such as placing orders are allowed.

> Connect ChatGPT and Codex to Public.com and trade stocks, crypto, and options from your chat or terminal. Powered by the Public MCP server with OAuth sign-in.

> codex mcp login public

> ChatGPT uses the accounts and trading permissions you authorize when you connect. Options strategies require the appropriate approval level.
