# Account revocation - AgentBank docs

**Official source** · AgentBank · official-doc · retrieved 2026-11-19 · [open the original](https://docs.useagentbank.com/security/account-revocation)

## Summary

AgentBank's revocation guide. ChatGPT and Claude remote connections are revoked from AgentBank connection settings, or by removing the plugin or connector in the AI client's settings. Local agents are disconnected by asking the agent to disconnect, which invalidates that installation's access and wallet authorization and clears its locally stored credentials; reconnecting requires a new browser authorization. If the device is lost or the agent is unavailable, app.useagentbank.com is used to manage access. Revocation stops that agent's access but is not a cancellation or refund for a payment already funded.

## Short quotes

> Disconnect an agent when you no longer want it to use your AgentBank account.

> Revoke the connection from AgentBank connection settings.

> Disconnect this agent from AgentBank. Explain the effect and ask me to confirm before revoking access.
