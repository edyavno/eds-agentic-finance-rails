# Connect your agent - AgentBank docs

**Official source** · AgentBank · official-doc · retrieved 2026-11-19 · [open the original](https://docs.useagentbank.com/getting-started/connect-your-agent)

## Summary

AgentBank's local setup guide for agents running on your device, connecting to production by default. Per-client install steps for Codex (`codex mcp add agentbank -- npx -y agent-bank-mcp@latest`), Claude Code (`claude mcp add agentbank -- npx -y agent-bank-mcp@latest`), Claude Desktop (claude_desktop_config.json), OpenClaw (openclaw.json, verified with `openclaw mcp doctor agentbank --probe`) and Hermes (`hermes mcp add agentbank --command npx --args -y agent-bank-mcp@latest`). Authorization happens through a browser link the owner opens and signs in to; the agent is told not to create a payment during setup.

## Short quotes

> Use this setup for an agent running on your device.

> Help me connect this agent to my AgentBank account. Do not create a payment.

> Do not paste wallet keys, sign-in tokens, or World ID proofs into chat.
