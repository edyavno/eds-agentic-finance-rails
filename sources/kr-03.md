**Official source** · Kraken (GitHub) · repo · retrieved 2026-11-19 · [open the original](https://github.com/krakenfx/kraken-cli)

## Summary

Kraken's GitHub repository for kraken-cli: one install covers crypto, tokenized US stocks and ETFs (for non-US customers), forex and futures; a built-in MCP server connects Claude, Cursor, Codex, Gemini and other MCP clients. The repo warns that the MCP server is local-first, that any agent connected to it uses the same configured Kraken account and API key permissions, that it should not be exposed or shared outside systems you control, and that the integration should be treated as alpha with least-privilege API keys. The repo also says the kraken CLI itself places orders without a confirmation prompt, and points agents' humans to rules for trading real money.
