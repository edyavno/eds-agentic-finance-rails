# Link overview (Plaid Docs)

**Official source** · Plaid Docs · official-doc · retrieved 2026-11-18 · [open the original](https://plaid.com/docs/link/)

## Summary

Plaid's documentation of Link, the client-side component people use to link accounts. It describes the flow: the app creates a temporary link_token, Link returns a temporary public_token when the person finishes, and the app exchanges it for a permanent access_token and item_id for the new Item. Link handles login, multi-factor authentication and, for OAuth banks, the handoff to the bank.

## Short quotes

> Link is the only available method for connecting accounts and authenticating users in Production.

> Call /item/public_token/exchange to exchange the public_token for a permanent access_token and item_id for the new Item.
