# Grok Connector for Stock & Options Trading on Public MCP

**Official source** · Public.com API docs · official-doc · retrieved 2026-11-19 · [open the original](https://public.com/api/docs/templates/grok)

## Summary

Grok setup for Public MCP: custom connector at grok.com/connectors with OAuth, or the Public Agent Skill (ZIP upload at grok.com/skills) with a Public API key pasted into chat. Public says to treat the key like a password.

## Short quotes

> Grok can connect through the hosted MCP server with OAuth, or through the Public Agent Skill with a Public API key.

> Treat the key like a password: only paste it into tools you trust, and never share it publicly.

> then paste it into your first message to Grok.

> Grok uses the accounts and trading permissions you authorize when you connect. Options strategies require the appropriate approval level.
