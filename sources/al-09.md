# Trading API MCP

**Official source** · Alpaca Docs · official-doc · retrieved 2026-11-19 · [open the original](https://docs.alpaca.markets/docs/alpaca-mcp-server)

## Summary

Trading API MCP docs: stocks, options, crypto orders; requires API keys; docs index at docs.alpaca.markets/us/llms.txt. Re-read 2026-11-19: the local server exposes 65 tools across Trading API and Market Data API. Trading covers stocks/ETFs (market, limit, stop, stop-limit, trailing stop, brackets), crypto (market, limit, stop-limit) and options (single-leg or multi-leg strategies). Configuration is by environment variables: ALPACA_API_KEY, ALPACA_SECRET_KEY, ALPACA_PAPER_TRADE (default true; set false to use live trading) and ALPACA_TOOLSETS (comma-separated toolsets: account, trading, watchlists, assets, stock-data, crypto-data, options-data, corporate-actions, news, fixed-income-data). Supported clients include Claude Desktop, VS Code, Cursor, PyCharm, Claude Code and Gemini CLI, local or remote. The docs say the server defaults to paper trading and warn never to paste API keys into chat.

## Short quotes

> Place and manage orders for stocks, options, and crypto (market, limit, stop, trailing stop, brackets, multi-leg spreads)

> The Trading API MCP server exposes 65 tools across Trading API and Market Data API.

> The server defaults to paper trading.

> Never paste API keys into chat.
