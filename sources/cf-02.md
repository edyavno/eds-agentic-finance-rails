# AgentPay MCP

**Official source** · Cashfree · official-doc · retrieved 2026-11-25 · [open the original](https://www.cashfree.com/docs/tools-ai/agentpay-mcp/overview)

## Summary

Cashfree developer overview for AgentPay MCP. An AI agent can pay everyday bills such as electricity, water, mobile and broadband from a customer's Cashfree AgentPay wallet, through India's Bharat Bill Payment System (BBPS). The agent talks to Cashfree through an MCP server and does not call Cashfree APIs directly. The first time, the customer opens a consent link, logs in with an OTP, and approves a mandate: standing permission to pay bills from the wallet, up to a monthly limit. The MCP server stores nothing and never keeps keys, tokens or bill data. The page has no publication date.

## Short quotes

> AgentPay lets your AI agent pay everyday bills, such as electricity, water, mobile and broadband, for you or your customers directly from their Cashfree AgentPay wallet.

> AgentPay pays bills through the Bharat Bill Payment System (BBPS), the bill payment network that connects most Indian billers.

> The first time, the customer opens a consent link, logs in with a one-time password (OTP) and approves a mandate: a standing permission for your agent to pay bills from their wallet, up to a monthly limit.

> The AgentPay MCP server turns each tool call into a Cashfree API call and returns the result. It fills in all the BBPS technical details for you and stores nothing, so it never keeps your keys, tokens or bill data.
