# Mastercard Developers Agent Toolkit

**Official source** · Mastercard Developers · official-doc · retrieved 2026-11-19 · [open the original](https://developer.mastercard.com/platform/documentation/agent-toolkit/)

## Summary

Mastercard Developers' page for its official Agent Toolkit, which connects AI assistants and IDEs to Mastercard Developers through the Model Context Protocol (MCP). The remote server is at https://developer.mcp.mastercard.com, is the recommended option, and the ChatGPT steps say to choose "No Authentication". A local option runs with npx (`@mastercard/developers-mcp`) or a prebuilt Claude Desktop file. The server serves developer documentation, API specs and guides; it is not Agent Pay. The page is a script-driven app, so the fingerprint below is of its Markdown version (the same address plus `index.md`).

## Short quotes

> The Mastercard Developers MCP server exposes product docs, API specs, and guides on Mastercard Developers as structured tools, so assistants can answer questions, discover operations, and generate code with the latest information.

> The remote option is easier to set up, requires minimal configuration, and does not require running an additional local process or installing dependencies such as Node or npx.

> Use "No Authentication" as the connection mechanism.

> claude mcp add --transport http mastercard-developers https://developer.mcp.mastercard.com
