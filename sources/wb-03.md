# GitHub - webull-inc/webull-openapi-mcp: Webull OpenAPI MCP · GitHub

**Official source** · Webull (GitHub) · repo · retrieved 2026-11-19 · [open the original](https://github.com/webull-inc/webull-openapi-mcp)

## Summary

Local OpenAPI MCP: stocks, options, futures, crypto, event contracts; 9 regions; risk controls (notional/quantity limits, symbol whitelist); audit log; 2FA flow. The repo also lists community features for the US (create posts and comments, list hot stocks, browse posts by symbol, view post details, list your own posts), combo orders (OTO, OCO, OTOCO, US only), option strategies and algo orders (TWAP, VWAP, POV, US only).

## Short quotes

> Place, modify, cancel orders for stocks, options, futures, crypto, and event contracts

> Market-specific notional limits (USD/HKD/CNH/JPY), quantity limits, symbol whitelist

> The server defaults to UAT (sandbox) environment.

> Create posts and comments, list hot stocks, browse posts by symbol, view post details, and list your own posts
