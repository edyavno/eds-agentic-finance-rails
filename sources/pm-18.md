# Model Context Protocol (MCP) | Stripe Documentation (Markdown version)

**Official source** · Stripe Docs · official-doc · retrieved 2026-11-19 · [open the original](https://docs.stripe.com/mcp.md)

## Summary

The Markdown version of Stripe's MCP page (the same document as pm-09), which includes the manual setup steps for each client. Recommended setup: agent plugins installed with `stripe agent setup` after installing the Stripe CLI. Manual setup: Claude Code (`claude mcp add --transport http stripe https://mcp.stripe.com/`, then `/mcp` to authenticate), Claude (the official Stripe connector on the web and in Claude Desktop; on Team and Enterprise accounts an owner adds it to the workspace first), Codex (`codex mcp add stripe --url https://mcp.stripe.com`; the ChatGPT desktop app, Codex CLI and Codex IDE extension share the same configuration), ChatGPT (the official Stripe plugin, with OAuth), VS Code, Cursor, and any other client using `https://mcp.stripe.com` as the server URL. The tool table marks Treasury tools as public preview, and `send_money`, `transfer_money` and `convert_currency` as needing human confirmation.

## Short quotes

> This command automatically detects which agents you use, and runs the applicable commands.

> For Team and Enterprise accounts, an owner must add the connector to the workspace before members can connect their Stripe accounts.

> The ChatGPT desktop app, Codex CLI, and Codex IDE extension support MCP servers and share the same configuration on your computer.

> Follow your client’s MCP setup instructions and use `https://mcp.stripe.com` as the server URL.
