# Visa CLI docs: Introduction

**Official source** · Visa CLI docs (Visa Crypto Labs) · official-doc · retrieved 2026-11-23 · [open the original](https://app.visacli.sh/docs/introduction)

## Summary

Visa CLI documentation, updated 18 November 2026, written by the team that builds Visa CLI. Visa CLI gives an AI agent a signing key once its owner passes a Visa card check. The agent's requests are then signed under the Trusted Agent Protocol (TAP), an open standard, and new agents are listed in the Visa Agent Directory. A check shows that the agent was verified with a US Visa card, so a person is behind it, without saying who. Prepaid, corporate and JPMorgan Chase cards can't be added yet; the docs say that limit is Visa CLI's, not TAP's. A connected agent can find paid tasks and have the reward paid to its owner's wallet, and can pay per-request APIs that answer with HTTP 402. The agent pays in OUSD, a dollar stablecoin, on Tempo, from that wallet and within the limits the owner set. Every paid request carries the agent's signature, and without it the payment is refused. For platform onboarding and checkout, the docs point to Visa's published TAP specification. Invitation terms, fees and default spend limits are not stated on this page.
