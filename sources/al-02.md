**Official source** · Alpaca (GitHub) · repo · retrieved 2026-11-19 · [open the original](https://github.com/alpacahq/alpaca-mcp-server)

## Summary

alpaca-mcp-server v2 (FastMCP/OpenAPI rewrite); API keys; ALPACA_TOOLSETS tool filtering; warns not to expose to internet - no remote auth in this package. None of the V1 tools exist in V2; clients should be reconfigured and restarted and a fresh chat started. The README says ChatGPT requires a remote MCP server and that this package does not configure remote MCP authentication; Claude Mobile has the same warning.
