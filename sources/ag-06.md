# Connect Claude - AgentBank docs

**Official source** · AgentBank · official-doc · retrieved 2026-11-19 · [open the original](https://docs.useagentbank.com/remote-mcp/claude)

## Summary

AgentBank's Claude remote-connection guide: a custom remote connector in Claude or Claude Desktop, no local MCP package required. Add it under Customize → Connectors → + → Add custom connector, name it AgentBank, enter https://mcp.useagentbank.com, then sign in through AgentBank's browser flow. Claude supports remote connectors on Free, Pro, Max, Team and Enterprise plans, with Free accounts limited to one custom connector. Team and Enterprise owners add AgentBank first in Organization settings → Connectors → Add → Custom → Web; each member then connects their own AgentBank account.
