# AgentPay MCP Integration Guide

**Official source** · Cashfree · official-doc · retrieved 2026-11-25 · [open the original](https://www.cashfree.com/docs/tools-ai/agentpay-mcp/integration-guide)

## Summary

Cashfree integration guide for the AgentPay MCP server. Production is at `https://mcp.cashfree.com/agentpay/mcp` and sandbox at `https://sandbox.cashfree.com/agentpay/mcp`. Agent builders need AgentPay access and a client API key, set up by Cashfree's sales team; a Cashfree merchant account is not required. A mismatched key and URL fails with HTTP 401. The page has no publication date.
