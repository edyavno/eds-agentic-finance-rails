# Coinbase MCP - Coinbase Developer Documentation

**Official source** · Coinbase Developer Platform · official-doc · retrieved 2026-11-18 · [open the original](https://docs.cdp.coinbase.com/ai-agents/coinbase-for-agents/coinbase-mcp)

## Summary

Official Coinbase MCP docs. Re-read 2026-11-18; earlier retrieved 2026-11-13 for the Send feedback section. Send feedback: you or your agent can send feedback about the Coinbase MCP through the coinbase_feedback_submit tool, limited to 2,000 characters, up to 6 submissions per user per day, and submissions are screened; the docs do not document an HTTP path named /feedback. ChatGPT setup: there are two options. A custom Coinbase MCP connection is for automated trading without approving each trade, and is the only option that supports x402 and Global Derivatives. The official Coinbase plugin for ChatGPT, available to US Coinbase users, shows Coinbase confirmation cards for order placement, edits, cancellations and USD–USDC conversions; read-only requests don't use cards, and ChatGPT's own tool permissions are separate. The ChatGPT trading integration does not expose x402 tools. A section on guiding agents to place orders still says Claude previews and asks to confirm while ChatGPT creates the order in one turn.

## Short quotes

> Coinbase confirmation cards cover order placement, edits, cancellations, and USD–USDC conversions. Read-only requests don't use cards.
