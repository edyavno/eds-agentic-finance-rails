# Coinbase MCP - Coinbase Developer Documentation

**Official source** · Coinbase Developer Platform · official-doc · retrieved 2026-11-19 · [open the original](https://docs.cdp.coinbase.com/ai-agents/coinbase-for-agents/coinbase-mcp)

## Summary

Official Coinbase MCP docs. Re-read 2026-11-18; earlier retrieved 2026-11-13 for the Send feedback section. Send feedback: you or your agent can send feedback about the Coinbase MCP through the coinbase_feedback_submit tool, limited to 2,000 characters, up to 6 submissions per user per day, and submissions are screened; the docs do not document an HTTP path named /feedback. ChatGPT setup: there are two options. A custom Coinbase MCP connection is for automated trading without approving each trade, and is the only option that supports x402 and Global Derivatives. The official Coinbase plugin for ChatGPT, available to US Coinbase users, shows Coinbase confirmation cards for order placement, edits, cancellations and USD–USDC conversions; read-only requests don't use cards, and ChatGPT's own tool permissions are separate. The ChatGPT trading integration does not expose x402 tools. A section on guiding agents to place orders still says Claude previews and asks to confirm while ChatGPT creates the order in one turn. Re-read 2026-11-19 for the per-app setup tabs. The page lists ten supported apps for the remote MCP: ChatGPT, Grok Bot, Grok, Muse, Hermes, Supertake, Perplexity Computer, Claude, Claude Code and Codex CLI. It says support is expanding as clients are approved, that Dynamic Client Registration alone does not mean a client is available yet, and that other or custom harnesses should use the CLI. Each app has its own steps. ChatGPT: a custom MCP server added under Plugins (if Add Custom MCP Server is missing, turn on developer mode in Settings), or the official Coinbase plugin. Grok Bot: Marketplace, search Coinbase, Add; a Coinbase connection already made in Grok should also appear in Grok Bot, and a connector added by one Bot is available to all of your Bots, so access is limited by selecting a dedicated portfolio on the approval screen. Grok: a Connect button that opens Grok with the setup prompt, or Plugins, search Coinbase, Add, Connect. Muse: share the page or the agent setup guide and use the setup prompt; no CDP API key is needed. Hermes: Hermes Agent app, Capabilities, Connectors tab, Coinbase Agents, Connect. Supertake: supertake.com, Settings, Trading, Connect on Coinbase, then follow the tooltip to turn on equities. Perplexity Computer: a Connect button, or Customize, Connectors, Add Connector. Claude: a one-step add button, or Customize, Connectors, Add custom connector with the server URL. Claude Code: `claude mcp add coinbase --transport http` with the server URL, then /mcp and Authenticate. Codex CLI: `codex mcp add coinbase --url` with the server URL, and `codex mcp login coinbase` if the browser does not open. Known limitation on hosted chat clients: high-reasoning and extended-thinking modes sometimes draft an order but stop short of executing it; the page suggests asking the agent to place the order explicitly, or using the CLI. CLI: it runs on your machine with a CDP API key; the key is created in the CDP Portal with a chosen portfolio, with Trade and Transfer enabled; Transfer allows moves between your portfolios only and does not allow withdrawals to external addresses; US Derivatives (Futures) only work in the default portfolio. Disconnect: to revoke Coinbase access, go to Coinbase Account, Security, Connections and revoke the connection; deleting a local skill or clearing a chat is not the same as revoking access.
