# Giving agents the ability to pay (Stripe)

**Official source** · Stripe · announcement · retrieved 2026-11-18 · [open the original](https://stripe.com/blog/giving-agents-the-ability-to-pay)

## Summary

Stripe blog post, 2026-04-29, on Link's wallet for agents. The consumer grants an agent access to their Link wallet through OAuth; the agent creates a spend request for a one-time-use card or a shared payment token, scoped by amount, currency and merchant; the consumer approves each request in Link (web, iOS or Android) and can track agent spending and manage connected agents in Link. Stripe says it plans spending limits and a way to let agents act without extra approval.

## Short quotes

> Today, each request requires the person’s review before the credential is shared with your agent.

> The person can track agent spending and manage connected agents directly in Link.
