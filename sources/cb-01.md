# Coinbase MCP - Coinbase Developer Documentation

**Official source** · Coinbase Developer Platform · official-doc · retrieved 2026-11-12 · [open the original](https://docs.cdp.coinbase.com/coinbase-for-agents/overview)

## Summary

Coinbase for Agents: remote MCP https://agents.coinbase.com/mcp via OAuth (DCR/CIMD, allowlisted clients) or local CLI with CDP API key; recommends isolated agent portfolio; crypto, equities, derivatives, x402 payments. Known issue: some hosted models preview but don't place orders.

## Short quotes

> The remote MCP connects directly to `https://agents.coinbase.com/mcp` via OAuth.

> Coinbase still approves clients through allowlisting, including DCR clients; DCR is not unrestricted self-service access.

> On hosted chat clients, high-reasoning and extended-thinking modes sometimes draft an order but stop short of placing it.

> spot crypto only, scoped to a specific portfolio selected when logging in or creating an API key.
