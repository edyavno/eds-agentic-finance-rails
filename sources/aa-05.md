# Aave MCP Tools

**Official source** · Aave · official-doc · retrieved 2026-11-23 · [open the original](https://aave.com/docs/mcp/tools)

## Summary

Aave tools reference for Aave MCP. Tools cover markets and reserves, positions (including `get_user_summary` for aggregate position and health factor), action builders (`preview_action` simulates; `prepare_action` builds an unsigned supply, borrow, withdraw or repay), rewards, swaps, leverage and orders (`submit_signed_order` relays an already-signed order), Savings GHO, DAO governance and guidance. Most tools take a `version` of `v3`, `v4`, or `all`. The live `tools/list` on the endpoint is the authority if it disagrees with the page. The page has no publication date.

## Short quotes

> `get_user_summary`| V3, V4| Aggregate position and health factor

> `preview_action`| V3, V4| Simulate a supply, borrow, withdraw or repay without executing, or, on V4 only, a quoted leverage, position swap or repay-with-supply

> `prepare_action`| V3, V4| Build an unsigned supply, borrow, withdraw or repay

> `submit_signed_order`| —| Relay an order the user has already signed
