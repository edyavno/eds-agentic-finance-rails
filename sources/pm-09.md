# Model Context Protocol (MCP) | Stripe Documentation

**Official source** · Stripe Docs · official-doc · retrieved 2026-11-19 · [open the original](https://docs.stripe.com/mcp)

## Summary

Stripe MCP server for API actions and knowledge search. Public preview. OAuth or agent API keys; OAuth sessions expire after 14 days; human confirmation in the Dashboard for certain actions; admins can toggle MCP access per environment; full-access and untagged restricted keys stop working after 2026-11-30.

## Short quotes

> Migrate by November 30, 2026. Starting in December, Stripe MCP will stop accepting full-access secret keys and restricted API keys without the Agent tag.

> OAuth refresh tokens expire after 14 days, and refreshing tokens doesn’t extend the session beyond 14 days from your initial authorization.

> Before an agent completes certain actions on your behalf, Stripe can require you to review and approve the request in the Dashboard.

> If you don’t approve the action within 24 hours, it expires.
