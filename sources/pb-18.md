# Items API reference (Plaid Docs)

**Official source** · Plaid Docs · official-doc · retrieved 2026-11-18 · [open the original](https://plaid.com/docs/api/items/)

## Summary

Plaid's Items reference. An access_token corresponds to an Item, which is a login at a financial institution; it does not expire but can be revoked with /item/remove. Plaid sends webhooks when access is about to expire (PENDING_DISCONNECT in the US and Canada, PENDING_EXPIRATION in the UK and EU) and when a person revokes permission (USER_PERMISSION_REVOKED, USER_ACCOUNT_REVOKED).

## Short quotes

> An access_token corresponds to an Item , which is a login at a financial institution.

> The `USER_PERMISSION_REVOKED` webhook may be fired when an end user has revoked the permission that they previously granted to access an Item.
