# Issuing for agents - Stripe Documentation

**Official source** · Stripe Docs · official-doc · retrieved 2026-11-23 · [open the original](https://docs.stripe.com/issuing/agents)

## Summary

Stripe documentation for Issuing for agents, marked as a private preview. It describes a way for a business to issue cards and credentials that agents can use to make purchases, with spend controls, real-time authorization, and transaction visibility, using Stripe Issuing APIs. Before a purchase, the business can decide what the agent can spend, where, and how much. Agents can pay through programmatic checkout, including creating a scoped Shared Payment Token (SPT) from an Issuing card for flows such as MPP or UCP, or through browser checkout using virtual card credentials, including a single-use card. The page also mentions agentic network tokens created from the Issuing card by Visa or Mastercard. Access is by application or by contacting Stripe. This is a business and platform product; the docs also describe a platform option that can issue commercial or consumer cards for customers on the platform.

## Short quotes
