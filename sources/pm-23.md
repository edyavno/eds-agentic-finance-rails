# What happens when AI agents start paying each other? Watch Mastercard Agent Pay for Machines in action

**Official source** · Mastercard · announcement · retrieved 2026-11-19 · [open the original](https://www.mastercard.com/global/en/news-and-trends/press/2026/october/Mastercard-Agent-Pay-for-Machines-in-action.html)

## Summary

Mastercard page dated October 20, 2026 on Agent Pay for Machines, which lets AI agents pay digital services such as AI models, data, computing power and APIs. It builds on x402. A business gives the agent a job and a spending limit, and the agent signs a payment voucher within that limit. Mastercard is opening Early Access to developers (buyer- and seller-side APIs, a toolkit, sandbox and documentation) after pilots with seven named partners. ## Short quotes

> It builds on x402, an open protocol that lets digital services request payment online, and connects it with the trust, security and reach of the Mastercard network.

> Following end-to-end pilots with Cloudflare, Ant International, AIsa, Base, BVNK, Coinbase and Hype, we’re also opening Agent Pay for Machines Early Access, giving developers access to the APIs, tools and documentation needed to begin building and testing agent-to-agent commerce experiences.

> The agent creates a digitally signed payment voucher, which is a secure promise to pay within its approved limit.

> Businesses set the task, permissions and spending limit for the AI agent. Agent Pay for Machines allows the agent to transact within those defined parameters rather than giving it unlimited spending authority.
