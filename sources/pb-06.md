# Introducing Agent Detection: building trust in the age of agentic finance

**Official source** · Plaid · announcement · retrieved 2026-11-18 · [open the original](https://plaid.com/blog/agent-detection-agentic-finance/)

## Summary

Plaid blog post by its Head of Fraud, 2026-11-16. Plaid launched Agent Detection, an SDK that lets banks, fintechs and other financial companies see whether a session is a person or an AI agent and which AI provider the agent is associated with, across login, sign-up and money movement. Plaid says it looks at thousands of signals and that, in its own side-by-side test on live traffic, it found 2.3x more agent sessions than competitors with no increase in false positives (company-reported). Plaid also says it is building toward a way for consumers to approve specific actions and is extending its Trust Index to score agent-driven sessions; both are described as plans.

## Short quotes

> Agent Detection goes a step further, looking at thousands of signals across devices, behavior, automation patterns, and network activity to identify whether an interaction is coming from a human or an AI agent, and which AI provider the agent is associated with.

> Businesses can use Agent Detection across their digital experiences, from login and sign-up to money movement, through a lightweight SDK that doesn't interrupt their existing user experience.

> In side-by-side testing on live traffic, Plaid’s Agent Detection identified 2.3x more agent sessions than competitors with no increase in false positives.

> we’re expanding Plaid’s Trust Index, which already scores sessions for risk, to evaluate agent-driven activity in context.
