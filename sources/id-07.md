# ERC-8004: Trustless Agents

**Official source** · Ethereum Improvement Proposals · official-doc · retrieved 2026-11-14 · [open the original](https://eips.ethereum.org/EIPS/eip-8004)

## Summary

Official ERC-8004: Trustless Agents. Status on the page is Draft (citation: ERC-8004: Trustless Agents [DRAFT]; created 2025-08-13). Proposes on-chain identity, reputation, and validation registries so agents can be discovered and trusted across organizational boundaries without pre-existing trust. Payments are orthogonal to this protocol and not covered here; examples show how x402 payments can enrich feedback signals.
