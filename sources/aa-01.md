# Aave MCP

**Official source** · Aave · official-doc · retrieved 2026-11-23 · [open the original](https://aave.com/docs/mcp)

## Summary

Aave documentation for Aave MCP, Aave's official MCP server. It gives agents a single interface to Aave V3 and V4 to discover markets, inspect positions, simulate protocol actions, and prepare transactions for a user's wallet to review and sign. The documented endpoint is `https://mcp.aave.com`. The server never holds private keys or signs transactions; it returns unsigned transactions or EIP-712 typed data and relays swap and leverage orders only after the user signs them. Read tools are side-effect-free, and `prepare_*` tools commit nothing. The page has no publication date.
