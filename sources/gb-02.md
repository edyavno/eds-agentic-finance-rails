# Finance plugin README (cursor/plugins, third_party/finance)

**Official source** · cursor/plugins (GitHub) · repo · retrieved 2026-11-18 · [open the original](https://github.com/cursor/plugins/tree/main/third_party/finance)

## Summary

README for the Finance plugin that connects Grok Bot to the Grok Finance connector through a remote MCP server hosted by xAI on the Grok connectors gateway. It lists what linking through Plaid shares (contact details, account and balance information, transactions, credit and loans, investments), says Grok syncs and stores linked data for the connector to work, says access is read-only and cannot move money, and says accounts can be unlinked from the Finance page on cursor.com. It needs Grok Bot 0.49 or newer. The README carries a general caution that third-party connectors are not built or maintained by xAI.

## Short quotes

> Access is read-only, xAI never sees or stores your bank login, and you can unlink accounts anytime from cursor.com.

> A financial connection is read-only, which means it can't be used to move money into or out of bank accounts.

> Grok syncs and stores linked account data (balances, transactions, holdings) so the connector can answer questions; this sync is required for the connector to work.
