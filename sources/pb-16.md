# Data Transparency Messaging migration guide (Plaid Docs)

**Official source** · Plaid Docs · official-doc · retrieved 2026-11-18 · [open the original](https://plaid.com/docs/link/data-transparency-messaging-migration-guide/)

## Summary

Plaid's guide to Data Transparency Messaging in Link. Plaid says it introduced the messaging to help customers stay in compliance with the 1033 rule: the person is told which data types an app requests and why. New US and Canada customers have been enrolled automatically since 2024-10-31, and the API only returns data for products the person consented to in Link.
