# Connect ChatGPT - AgentBank docs

**Official source** · AgentBank · official-doc · retrieved 2026-11-19 · [open the original](https://docs.useagentbank.com/remote-mcp/chatgpt)

## Summary

AgentBank's ChatGPT remote-connection guide: enable developer mode in Settings → Security and login (availability depends on account and workspace policy), add AgentBank in ChatGPT Plugins with the connection URL https://mcp.useagentbank.com, complete AgentBank's browser sign-in, then add AgentBank from the tools menu in a new chat and confirm the connected account is yours. Troubleshooting: use the URL exactly without adding /mcp, refresh the connection if tools change.
