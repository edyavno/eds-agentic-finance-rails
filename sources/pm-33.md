# pay.sh

**Official source** · pay.sh · official-doc · retrieved 2026-11-23 · [open the original](https://pay.sh/)

## Summary

The pay.sh website describes a way for agents to pay per API call in stablecoins, and for API providers to charge those calls. It says pay.sh is built on the open payment protocols x402 and MPP, with settlement on Solana. It lists stablecoins including USDC, USDT, and CASH, and says settlement paths are built for calls as little as $0.001. The page also shows a minimum call of about $0.001 and settlement of about 400ms. It includes a command-line quick start (brew install pay). The page does not state a launch date.

## Short quotes

> pay.sh is built on top of open payment protocols x402 and MPP.

> Use any major stablecoin including USDC, USDT, and CASH, to make payments permissionlessly with settlement paths built for calls as little as $0.001.
