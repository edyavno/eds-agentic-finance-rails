# What we learned building the UK’s first agentic bank payment

**Official source** · GoCardless · announcement · retrieved 2026-11-27 · [open the original](https://gocardless.com/blog/engineering-learnings-first-agentic-payment)

## Summary

GoCardless engineering post, last edited November 2026 (the exact day is not given). It describes a live donation to Trussell, set up through a website chat agent and completed with Direct Debit under the FCA's AI Live Testing initiative. Behind it is a GoCardless-hosted MCP server that lets a business's AI agent set up a Direct Debit mandate or take a one-off bank payment.
