# Helping personal agents shop more intelligently and reliably with Link (Stripe)

**Official source** · Stripe · announcement · retrieved 2026-11-18 · [open the original](https://stripe.com/blog/helping-personal-agents-shop-more-intelligently-and-reliably-with-link)

## Summary

Stripe blog post, 2026-09-29. Link now supports incremental authorization so an agent can request a higher approved amount; Link can give an agent a URL for a 3D Secure challenge; with a consumer's permission an agent can use Link financial insights (consumer-permissioned transaction data through Stripe's Financial Connections from more than 12,000 institutions) to recommend purchases; eligible Link purchases may carry free purchase protections, with Muse the first agent to offer them. Stripe says it plans spending controls that let people set an agent's budget without approving each transaction.

## Short quotes

> Consumers choose which bank and credit card accounts to share and can revoke access at any time.

> Muse is the first AI agent to offer purchase protections through Link’s wallet for agents.
