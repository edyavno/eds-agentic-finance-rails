# Aave MCP llms.txt

**Official source** · Aave · official-doc · retrieved 2026-11-23 · [open the original](https://mcp.aave.com/llms.txt)

## Summary

Machine-readable description of Aave's official MCP for V3 and V4 markets, positions, governance, and transaction preparation. The endpoint is `https://mcp.aave.com/` over Streamable HTTP; `/mcp` is an alias. There is no API key and no sign-in. `preview_*` simulates an action; `prepare_*` returns an unsigned transaction or EIP-712 typed data for the user's wallet to sign. The server never holds keys and never submits, except that `submit_signed_order` and `cancel_order` relay what the user already signed. Calls are counted for product analytics (tool name, MCP method, protocol version, chain id, client name and version); a named wallet is counted under a keyed hash, so no wallet address is recorded. No keys, signatures, transaction content or prompt text are collected. The file has no publication date.

## Short quotes

> Official Aave MCP for V3 and V4 markets, positions, governance, and transaction preparation.

> Endpoint: https://mcp.aave.com/ (Streamable HTTP, POST; /mcp is an alias)

> preview_* simulates an action; prepare_* returns the unsigned transaction or EIP-712 typed data for the user's own wallet to sign.

> Non-custodial: the server never holds keys and never submits (only submit_signed_order and cancel_order relay what the user already signed). No API key and no sign-in of any kind.
