# Meta Muse Connector for Stock & Options Trading on Public MCP

**Official source** · Public.com API docs · official-doc · retrieved 2026-11-19 · [open the original](https://public.com/api/docs/templates/meta-muse)

## Summary

Meta Muse (muse.ai) connects to the Public MCP server with a Public API key as bearer token; Public's setup message tells Muse to use the key only for that session and never place trades without explicit confirmation.

## Short quotes

> Muse connects with a Public API key instead of OAuth. Treat the key like a password: only paste it into tools you trust, and never share it publicly. This connection can view your account information and place trades using real money in your Public account.

> Use my key only for this session, and never place trades without my explicit confirmation.

> Muse uses the accounts and trading permissions associated with your Public API key. Options strategies require the appropriate approval level.
