**Official source** · Public.com API docs · official-doc · retrieved 2026-11-19 · [open the original](https://public.com/api/docs/templates/perplexity)

Perplexity setup for the Public hosted MCP: search for Public under Plugins (or Customize > Connectors), connect, and authenticate with OAuth. Perplexity Computer users are pointed to a separate Agent Skill guide.
