# kraken-cli - Kraken docs

**Official source** · Kraken · official-doc · retrieved 2026-11-19 · [open the original](https://docs.kraken.com/home/cli)

## Summary

kraken-cli is a compiled CLI for trading and account management on the Kraken exchange, with three binaries: kraken (CLI), kraken-mcp (MCP server) and kraken-shell. 188 commands across 15 groups cover crypto spot (1,400+ pairs), xStocks tokenized equities (79 assets), forex (11 pairs), perpetual futures (317 contracts), inverse and fixed-date futures (20 contracts) and earn/staking. Built-in paper trading runs against live prices with no authentication. kraken auth login saves a restricted Spot API key with no withdrawal rights and an expiry date (90 days by default); --read-only creates a key that cannot trade; keys created by hand come from Settings → API or the Futures interface via the kraken setup wizard.
