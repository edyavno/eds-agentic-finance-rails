# Aave MCP Safety

**Official source** · Aave · official-doc · retrieved 2026-11-23 · [open the original](https://aave.com/docs/mcp/safety)

## Summary

Aave safety documentation for Aave MCP. The server reads live protocol data and builds transactions; it never signs them, and the user's wallet is the last gate before anything reaches a chain. The server holds no private keys and cannot move funds. Read tools are side-effect-free. A `prepare_*` tool returns an unsigned transaction, an earlier approval step, or EIP-712 typed data, and commits nothing. Only `submit_signed_order` and `cancel_order` change state, and only by relaying what the user has already signed. The page has no publication date.

## Short quotes

> Aave MCP reads live protocol data and builds transactions. It never signs them, and the user’s wallet is the last gate before anything reaches a chain.

> The server holds **no private keys** and cannot move funds.

> Two tools change state. `submit_signed_order` relays an order the user has **already signed** , and `cancel_order` relays a signed cancellation. Neither can create or sign anything of its own.
