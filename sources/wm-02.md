# Making It Possible for Agents to Shop on Behalf of Customers

**Official source** · Walmart · announcement · retrieved 2026-11-25 · [open the original](https://corporate.walmart.com/news/2026/10/Making-It-Possible-for-Agents-to-Shop-on-Behalf-of-Customers)

## Summary

Walmart newsroom article dated 21 October 2026 announcing Agent Profiles and the Walmart Agent Gateway. Shoppers set a spending limit, can see purchases from every agent, and can delete an Agent Profile at any time. Walmart says customers must approve agent purchases by default, and that Walmart may require additional approvals even within an agent's spending limits. Agents do not receive payment-card information and cannot add or change payment methods. Walmart's returns process applies.

## Short quotes

> Customers must approve agent purchases by default, and Walmart may require additional approvals even for purchases within an agent’s spending limits.

> Choose a spending limit and see purchases from every agent. Delete an Agent Profile at any time.

> Agents don’t receive customers’ payment-card information and can’t add or change a customer’s payment methods.
