# Adyen Merchants Can Now Offer Klarna in AI Agent Checkout

**Official source** · Klarna and Adyen (Business Wire release on Klarna's investor site) · announcement · retrieved 2026-11-23 · [open the original](https://investors.klarna.com/News--Events/news/news-details/2026/Adyen-Merchants-Can-Now-Offer-Klarna-in-AI-Agent-Checkout/default.aspx)

## Summary

Klarna and Adyen press release dated 20 November 2026. Shoppers can pay with Klarna when an AI agent checks out through Adyen Agentic, which the release calls Adyen's agentic commerce suite. Klarna is the first payment option beyond cards there. Merchants that already offer Klarna through Adyen can switch it on with no new integration work. The agent shows the same Klarna options the merchant already offers, such as paying in full, in interest-free installments or with financing. Shoppers review and confirm every purchase before it is completed. Adyen built the integration on Klarna's open payment handler, a published specification that any payment provider can use to add Klarna to AI agent checkout; Darren Moore of Klarna says Adyen is the first to bring it live. The release does not link the handler specification, so its URL is unknown, and it does not name the AI platforms where the checkout is available.
