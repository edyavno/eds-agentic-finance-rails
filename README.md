# Ed's Agentic Finance Rails

**Connect an AI agent to a brokerage account, safely.**

A source-linked wiki of how brokers and financial services let AI agents in: which ones offer official access, how it works, who approves the agent's orders, and how to build against it. Every fact links to a source; anything not confirmed says `unknown`.

> Status: **draft**. Nothing here has been reviewed by a person yet.

## Use it

- **People:** start with the [overview](overview.md), the [directory](directory.md) and the [approval models](approval-models/README.md).
- **Engineers:** see [Build it](build/README.md).
- **AI agents:** clone the repo and load [llms.txt](llms.txt), [AGENTS.md](AGENTS.md) and [data/providers.json](data/providers.json) into context. Everything works offline with no tooling.

```bash
git clone https://github.com/edyavno/eds-agentic-finance-rails
```

## What is in the repo

| Path | What |
|---|---|
| `providers/` | One page per provider, with a YAML header of key fields |
| `sources/` | One short card per source (summary, short quotes, fingerprint), never a full copy |
| `approval-models/` | The five approval models |
| `rails/` | Shared plumbing: OAuth MCP, local servers, payments, identity, mandates |
| `build/` | Connection commands, human-in-the-loop patterns, starter prompts |
| `comparisons/` | Side-by-side views |
| `analyses/` | Saved answers to good questions |
| `index.md`, `directory.md`, `llms.txt`, `data/` | Generated from the pages and committed |
| `overview.md`, `gaps.md`, `log.md`, `changelog/` | Context, open questions, history |
| `schema/` | JSON Schema for page headers |
