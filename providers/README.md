# Providers

A provider here is a broker or exchange that lets an AI agent connect to a trading account. Each provider has its own page. A page says whether an agent can place orders, who approves each order, what the agent can see, and how to connect, and it names the source behind every fact. Where no source confirms a value, the page says "unknown".

## Which providers are covered?

Alpaca, Coinbase, Interactive Brokers, Robinhood and Webull are the wiki's five launch brokers; Public, Scalable Capital and Kraken were added on 2026-11-19. "Approval model" is the way the provider decides who says yes before an agent's order reaches the market; each model is explained in [approval models](../approval-models/README.md). "Status" is how the broker offers agent access, for example an official [MCP](../glossary.md#mcp) server.
