# What changed: 2026-11-19

Five items were added: news reports on Chase and agent card payments, OpenAI's steps for adding a Chase card to ChatGPT Wallet, setup steps for the AI apps that Coinbase, Robinhood, Webull, Alpaca, Stripe and AgentBank support, three new provider pages (Public, Scalable Capital and Kraken), and new sections on Mastercard's developer MCP server, Agent Pay for Machines and Open Finance US.

- **Chase and card numbers.** [Banks and outside agents](../personal-money/banks-and-outside-agents.md#what-about-shopping-with-a-card) now covers a Wall Street Journal report of 2026-11-13 that JPMorgan Chase blocks agents when consumers give the bots their card information. The same report says cards from Bank of America, Capital One and Citigroup are being used by agents when consumers enable them. Both are third-party sources.
- **Link and virtual cards.** [Link wallet for agents](../payments/link-wallet-for-agents.md#does-link-work-with-chase-cards) describes the one-time virtual card Stripe uses for Chase cards. [Merchants and outside agents](../payments/merchants-and-outside-agents.md#what-do-merchants-say-about-agent-virtual-cards) adds what merchants say about its cost.
- **Chase cards in ChatGPT Wallet.** [ChatGPT Wallet](../payments/chatgpt-wallet.md#how-do-i-add-a-chase-card) lists the steps to add a Chase card: approve the connection in the Chase mobile app, as the primary cardholder.
- **Coinbase from your AI app.** [Coinbase](../providers/coinbase.md#how-do-i-connect-coinbase-from-my-ai-app) now has a table of how to connect from each of the ten apps Coinbase lists (ChatGPT, Grok Bot, Grok, Muse, Hermes, Supertake, Perplexity Computer, Claude, Claude Code and Codex CLI), plus how to revoke access and what limits apply to a CLI API key. [Grok Bot](../personal-money/grok-bot.md#can-grok-bot-connect-to-coinbase) says how to add Coinbase there and that connectors are account-wide across your Bots. The source is Coinbase's own docs.
- **New provider pages.** [Public](../providers/public.md) (hosted MCP, connector steps for six AI apps, the self-hosted server's order gate), [Scalable Capital](../providers/scalable-capital.md) (four MCP access levels; orders need Full access and your confirmation of each order preview) and [Kraken](../providers/kraken.md) (a local MCP server that asks you to approve each order, withdrawal or transfer, with built-in paper trading). The [Trading](../trading.md) page, the [overview](../overview.md) and [per-order confirm](../approval-models/per-order-confirm.md) now include them.
- **Connecting from your AI app.** New sections on [Robinhood](../providers/robinhood.md#how-do-i-connect-robinhood-from-my-ai-app), [Webull](../providers/webull.md#how-do-i-connect-webull-from-my-ai-app), [Alpaca](../providers/alpaca.md#how-do-i-connect-alpaca-from-my-ai-app), [Stripe](../payments/stripe.md) and [AgentBank](../payments/agentbank.md#how-do-i-connect-agentbank-from-my-ai-app) list how to connect from each app the provider documents.
- **Mastercard.** [Mastercard Agent Pay](../payments/mastercard-agent-pay.md#does-mastercard-have-an-mcp-server) now answers whether Mastercard has an MCP server: yes, an official, free server for Mastercard Developers at `https://developer.mcp.mastercard.com`, with no sign-in, that serves documentation only. Whether Agent Pay itself has an MCP server is still unknown. A new section covers [Agent Pay for Machines](../payments/mastercard-agent-pay.md#what-is-agent-pay-for-machines) (announced 2026-10-20: built on x402, a spending limit set by the business, signed payment vouchers, Early Access for developers; price, countries and how to join are unknown) and a short note on [Open Finance US](../payments/mastercard-agent-pay.md#what-about-mastercard-open-finance-us). [x402](../payments/x402.md) and [Agent payments](../rails/agent-payments.md) link to it, and [Gaps](../gaps.md) is updated.
- **Robinhood.** Where to change Trade approvals (Agent Settings, under Safety Controls), the MCP account requirements, including that it counts toward the limit of 10 self-directed individual investing accounts, and the crypto account rules.
- **Stripe.** Stripe's MCP is in public preview. Stripe says to migrate by 2026-11-30, because from December it stops accepting secret keys and restricted keys without the Agent tag. The page adds Stripe's option to require your approval in the Dashboard before an agent completes certain actions, and how to revoke access.
- **AgentBank.** How to revoke an agent's access and set approval thresholds.
- **Webull.** Sign-in and account selection for Cloud MCP, market data rules, the tool to revoke an instruction, and community tools that post under your account.
- **Alpaca.** Order types are now documented for its Trading MCP server, so that item left [Gaps](../gaps.md). The local server defaults to paper trading.
- **Glossary.** New entries: [Agentic token](../glossary.md#agentic-token), [Connector](../glossary.md#connector), [Agent skill](../glossary.md#agent-skill) and [Dead man's switch](../glossary.md#dead-mans-switch).
