# Connect an MCP client

These are the commands and URLs the providers document. Use the paper or sandbox option first where one exists.

## Robinhood

```bash
claude mcp add robinhood-trading --transport http https://agent.robinhood.com/mcp/trading
codex mcp add robinhood-trading --url https://agent.robinhood.com/mcp/trading
```

Both commands are from Robinhood's onboarding page, which also lists other clients.[^rh-01] Trading happens only in your Robinhood Agentic account.[^rh-01]

## Coinbase

```bash
claude mcp add coinbase --transport http https://agents.coinbase.com/mcp
codex mcp add coinbase --url https://agents.coinbase.com/mcp
```

On the approval screen, select only the portfolio the agent should use.[^cb-01][^cb-03]

## Webull (Cloud MCP)

```bash
codex mcp add webull --url https://api.webull.com/mcp
```

Other clients take `https://api.webull.com/mcp` as the server URL.[^wb-02] Orders are prepared as instructions that you confirm in the Webull app.[^wb-02]

## Interactive Brokers

Add a custom connector or remote MCP server with the URL `https://api.ibkr.com/v1/api/mcp-public`, then sign in through IBKR.[^ib-08]

## Alpaca

Hosted (OAuth) servers for Claude Code, as documented by Alpaca:[^al-03]

```json
{
  "mcpServers": {
    "alpaca-trading": { "type": "http", "url": "https://api.alpaca.markets/mcp" },
    "alpaca-trading-paper": { "type": "http", "url": "https://paper-api.alpaca.markets/mcp" }
  }
}
```

The local v2 server runs over stdio with API keys; do not expose it to the internet.[^al-02]

## Common pitfalls

- **The agent previews but never orders.** Coinbase documents this on some hosted reasoning modes; ask explicitly or use its CLI.[^cb-01]
- **Old tool names.** Alpaca's v2 server removed all v1 tools; start a fresh session after upgrading.[^al-02]
- **Wrong environment.** Check whether a local server defaults to sandbox or production.[^wb-03][^tt-03]
